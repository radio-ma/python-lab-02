# Онлайн-курс (Online Course)

Консольное приложение на Python для управления образовательными курсами, учёта успеваемости студентов и автоматического расчёта персональных скидок на обучение.

Проект разработан в рамках лабораторной работы №2 «Модули и пакеты Python. ООП» по дисциплине «Теория алгоритмов».

- **Вариант:** №21 — «Онлайн-курс»
- **Объекты:** Студент, Курс, Успеваемость
- **Задача:** Расчёт успеваемости студента, скидок на курс в зависимости от успеваемости
- **Разработчик:** Суворов Иван
- **Уровень сложности:** Well-done
- **Язык программирования:** Python 3.14
- **База данных:** SQLite
- **Контейнеризация:** Docker

---

## 1. Описание приложения

«Онлайн-курс» — приложение, позволяющее создавать каталог образовательных курсов (стандартных и интенсивных), регистрировать студентов и учитывать их успеваемость (баллы за домашние задания, экзамены и процент посещаемости).

На основании академических результатов программа вычисляет итоговый средневзвешенный балл, определяет статус учащегося («Отлично», «Хорошо», «Удовлетворительно», «Неудовлетворительно») и предоставляет персональные скидки на обучение, включая бонус за 100% посещаемость.

Приложение использует объектно-ориентированный подход и модульную архитектуру. Данные сохраняются в реляционной базе данных SQLite (`data/course.db`) и автоматически восстанавливаются при повторном запуске программы.

## 2. Возможности приложения

- Создание стандартных курсов с указанием названия, базовой стоимости, часов и флага сертификата
- Создание интенсивных курсов с указанием ментора, практических проектов и индивидуального лимита скидки
- Регистрация студентов с валидацией имени и email
- Автоматическое присвоение идентификаторов средствами SQLite
- Учёт успеваемости по формуле средневзвешенного балла (ДЗ 40%, экзамен 40%, посещаемость 20%)
- Динамический расчёт скидок:
  - «Отлично» ($\ge 90$ баллов) — скидка **25%**
  - «Хорошо» ($\ge 75$ баллов) — скидка **15%**
  - «Удовлетворительно» ($\ge 60$ баллов) — скидка **5%**
  - «Неудовлетворительно» ($< 60$ баллов) — скидка **0%**
  - Дополнительный бонус за 100% посещаемость — **+5%**
- Формирование рейтинга курсов по популярности
- Получение индивидуальной академической и финансовой статистики студента
- Определение лучшего студента платформы и самого популярного курса
- Экспорт официальных отчётов в форматы Word (.docx) и Excel (.xlsx)
- Постоянное хранение информации в SQLite с внешними ключами
- Автоматическое тестирование с использованием pytest (34 теста)
- Запуск приложения в Docker-контейнере с подключением тома

## 4. Объектно-ориентированная архитектура

В основе приложения лежат следующие классы:

### Course

Абстрактный базовый класс учебного курса (`ABC`).
- Содержит общие свойства курсов: `course_id`, `title`, `base_price`, `hours`.
- Защищает поля через управляемые атрибуты (`@property` и сеттеры): идентификатор и часы строго $> 0$, название непустое, цена $\ge 0$.
- Определяет общий интерфейс расчёта стоимости со скидкой через абстрактный метод `calculate_final_price()`.
- Переопределяет dunder-методы `__init__`, `__str__`, `__repr__`, `__eq__`.

### StandardCourse

Класс стандартного онлайн-курса, наследующий `Course`.
- Дополнительные свойства: `has_certificate` (наличие сертификата), `max_discount_percent` (максимальная скидка до 30%).
- Реализует полиморфный расчёт стоимости с ограничением скидки по установленному лимиту.
- Переопределяет dunder-методы `__init__`, `__str__`, `__repr__`.

### IntensiveCourse

Класс интенсивного курса с наставником, наследующий `Course`.
- Дополнительные свойства: `mentor_name` (ФИО наставника), `projects_count` (число проектов), `max_discount_percent` (лимит скидки до 20%).
- Реализует полиморфный расчёт стоимости с учётом затрат на менторское сопровождение.
- Переопределяет dunder-методы `__init__`, `__str__`, `__repr__`.

### Student

Класс учащегося образовательной платформы.
- Поля: `student_id`, `full_name`, `email`.
- Валидация через сеттеры: проверка непустоты имени и синтаксиса email (наличие `@` и `.`).
- Переопределяет dunder-методы `__init__`, `__str__`, `__repr__`, `__eq__`.

### AcademicPerformance

Класс успеваемости студента по дисциплине.
- Поля: `performance_id`, `student_id`, `course_id`, `homework_score`, `exam_score`, `attendance_rate`.
- Числовые атрибуты проверяются на вхождение в диапазон $0.0 \dots 100.0$.
- Методы `calculate_final_score()`, `get_status()`, `calculate_discount()`, `update_scores()`.
- Переопределяет dunder-методы `__init__`, `__str__`, `__repr__`, `__eq__`.

## 5. Расчёт успеваемости и скидок

### Итоговый балл

$$S_{\text{final}} = 0.4 \times S_{\text{hw}} + 0.4 \times S_{\text{exam}} + 0.2 \times S_{\text{att}}$$

### Академический статус

- **Отлично:** $S_{\text{final}} \ge 90.0$
- **Хорошо:** $75.0 \le S_{\text{final}} < 90.0$
- **Удовлетворительно:** $60.0 \le S_{\text{final}} < 75.0$
- **Неудовлетворительно:** $S_{\text{final}} < 60.0$

### Шкала скидок

- За статус «Отлично» начисляется **25%**
- За статус «Хорошо» начисляется **15%**
- За статус «Удовлетворительно» начисляется **5%**
- За статус «Неудовлетворительно» — **0%**
- При 100% посещаемости начисляется дисциплинарный бонус: **+5%**

Итоговая стоимость курса рассчитывается с учётом ограничения максимальной скидки курса ($D_{\text{max}}$):
$$P_{\text{final}} = P_{\text{base}} \times \left(1 - \frac{\min(D, D_{\text{max}})}{100}\right)$$

## 6. Установка и запуск

### Требования

Для локального запуска необходимы:
- Python 3.10+ (рекомендуется Python 3.14)
- pip
- Библиотеки из `requirements.txt`:
  - `python-docx` — создание отчётов Word
  - `openpyxl` — создание таблиц Excel
  - `pytest` — автоматическое тестирование

SQLite встроен в стандартную библиотеку Python (`sqlite3`) и не требует отдельной установки.

### Инструкции по запуску

Откройте терминал в директории `python_lab_02`:

1. Создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   ```

2. Активируйте окружение:
   - В Linux / macOS:
     ```bash
     source .venv/bin/activate
     ```
   - В Windows (PowerShell):
     ```powershell
     .\.venv\Scripts\Activate.ps1
     ```

3. Установите зависимости:
   ```bash
   python -m pip install -r requirements.txt
   ```

4. Запустите приложение:
   ```bash
   python main.py
   ```

Для завершения работы выберите пункт `0`.

## 8. Хранение данных в SQLite

База данных располагается по адресу:
```text
data/course.db
```

База содержит три связанные таблицы:
- `courses` — каталог учебных курсов, базовые цены и параметры скидок;
- `students` — зарегистрированные студенты (`email UNIQUE`);
- `performances` — ведомость успеваемости с внешними ключами (`FOREIGN KEY`) на студентов и курсы, а также составным ограничением `UNIQUE(student_id, course_id)`.

Включена проверка целостности `PRAGMA foreign_keys = ON`. При повторном запуске программы состояние объектов автоматически восстанавливается из БД.

## 9. Запуск через Docker

### Сборка образа

```bash
docker build -t online-course-app .
```

### Запуск контейнера с сохранением данных

```bash
docker run --rm -it -v course-data:/app/data online-course-app
```

Параметры:
- `--rm` — автоматическое удаление контейнера после завершения работы;
- `-i` — интерактивный ввод;
- `-t` — выделение псевдо-терминала;
- `-v course-data:/app/data` — том Docker Volume для персистентного хранения базы данных SQLite.
